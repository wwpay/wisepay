## 인증 문제

### 로그인이 안 된다
**확인 순서:**
1. ID/비밀번호 대소문자, 전각/반각 확인
2. Caps Lock 켜져 있는지 확인
3. 비밀번호 분실 시 → GAS 편집기에서 users 시트 직접 확인

### 자꾸 로그아웃된다
- 열람자(wisejp): 1시간 비활동 시 자동 로그아웃 → 정상 동작
- 관리자(wiseadmin): 자동 로그아웃 없음 → 다른 원인 확인

### 다른 기기에서 로그인이 안 된다
- 계정 자체는 공유 가능 (GAS users 시트 기준)
- 동시 접속 제한 없음

## 데이터 연동 문제

### 저장했는데 데이터가 없어졌다
**체크리스트:**
- [ ] GAS URL이 올바른지 확인 (설정 화면에서 연결 테스트)
- [ ] exec URL을 사용하고 있는지 확인 (Dev URL은 본인만 접근 가능)
- [ ] 구글 시트에서 직접 급여데이터 시트 확인

### 저장 버튼을 눌렀는데 에러가 난다
**확인 순서:**
1. 인터넷 연결 확인
2. GAS URL 설정 화면에서 연결 테스트
3. GAS 재배포 필요한지 확인 (최근 GAS 코드 변경이 있었으면)
4. 브라우저 콘솔(F12)에서 에러 메시지 확인

### 구글 시트와 앱 데이터가 다르다
1. 강력 새로고침: Ctrl+Shift+R
2. 설정 → GAS URL → 연결 테스트 → 데이터 다시 불러오기
3. 그래도 다르면 구글 시트 직접 확인

### GAS URL을 바꿨더니 데이터가 없다
- 새 배포 시 URL이 바뀜 → 앱 설정에서 새 URL 입력
- 데이터는 구글 시트에 있음 → URL만 맞게 설정하면 됨

## 급여 계산 문제

### 소득세 금액이 freee랑 다르다
**확인 순서:**
1. 세액표 적용 기준 확인
   - 2025년 11월분 이전: R6/R7 세액표
   - 2025년 12월분 이상: R8 세액표 (익월 10일 지급 기준)
2. 甲欄/乙欄 구분 확인 (기본값: 甲欄)
3. 부양수(扶養数) 확인 — 사원정보의 families 배열에서 16세 이상 카운트
4. 표준보수월액이 올바른지 확인

### 건강보험료가 이상하다
1. 보험료율 설정 화면에서 현재 적용 요율 확인
2. 적용 시작월(from) 확인 — 건강보험은 3월분부터 변경
3. 표준보수월액 확인 (협회けんぽ 등급표 기준)

### 개호보험료가 안 붙는다
- 40세 생일이 속하는 달부터 적용 (만 40세)
- 65세 생일이 속하는 달의 전달까지 적용
- 생년월일 입력이 올바른지 확인

### 자녀육아지원금이 0이다
- 2026년 4월분부터 적용 (0.23%)
- 이전 달은 0이 맞음
- 보험료율 데이터에 2026-04 rateHistory 항목 있는지 확인

### 전월과 금액이 다른데 이유를 모르겠다
1. 보험료율 변경 시기인지 확인 (3월/4월)
2. 표준보수월액 변경됐는지 확인
3. 부양가족 변경됐는지 확인
4. 주민세 변경됐는지 확인 (6월 갱신)

## 알림 문제

### 이메일 알림이 안 온다

**1. GAS 권한 확인:**
1. Apps Script 편집기 열기
2. sendDataInputReminderEmail 함수 선택
3. ▶ 실행 → 권한 팝업이 뜨면 허용
4. 안 뜨면 appsscript.json OAuth 범위 확인

**2. appsscript.json 범위 확인:**
```json
"oauthScopes": [
  "https://www.googleapis.com/auth/gmail.send",
  "https://www.googleapis.com/auth/script.send_mail"
]
```
없으면 추가 후 GAS 재배포

**3. 하루 1회 제한 리셋 (테스트 시):**
브라우저 F12 → Application → Local Storage에서 아래 키 삭제:
- lastDataInputReminderEmail
- lastSendReminderEmail
- lastPayConfirmReminderEmail

### 말풍선이 안 뜬다

**확인 순서:**
1. wiseadmin으로 로그인했는지 확인 (wisejp는 알림 없음)
2. 브라우저 콘솔에서 확인:
   ```javascript
   checkAndShowPayrollAlerts([...paidYMs])
   ```
3. 로그에서 unpaidYM=null 이면 → 이미 송금완료된 달만 있음 (정상)
4. 로그에서 기존balloon=... 이면 → 이미 말풍선 떠있는 상태

**테스트 방법:**
```javascript
_testAlert(5)   // 알림 2번 (노란 말풍선)
_testAlert(11)  // 알림 3번 (파란 말풍선)
_testAlert1()   // 알림 1번 (이메일 테스트)
```

### 말풍선이 사라지지 않는다
- 확인 버튼 누르면 잠깐 닫힘 (다음 접속 시 재표시 — 정상)
- 영구적으로 사라지려면 → 🔒 송금 완료 버튼 클릭

### 브라우저 푸시 알림이 안 온다
1. 브라우저 알림 권한 확인: Chrome → 설정 → 개인정보 → 사이트 설정 → 알림
2. wwpay.netlify.app이 허용되어 있는지 확인
3. 콘솔에서 직접 테스트:
   ```javascript
   sendPushNotification('테스트', '테스트 알림', 'test')
   ```

## 백업 복원 문제

### 백업 파일을 받았는데 복원이 안 된다
1. 파일 형식 확인: 사원_backup_*.json 또는 급여_backup_*.json
2. 사원 백업으로 급여 복원 시도하면 오류 → 파일 종류 확인
3. 파일이 손상됐을 수 있음 → JSON 유효성 검사

### 구글 시트 자동 백업이 안 만들어진다
1. GAS 트리거 확인: Apps Script → 트리거 → backupWeekly 존재하는지
2. 없으면 createWeeklyBackupTrigger() 함수 실행

### 복원 후 데이터가 이상하다
1. 사원번호(empNo) 기준으로 매칭 → 사원번호 변경했으면 매칭 안 됨
2. 복원 전 현재 데이터 백업 권장

## GAS 문제

### GAS 연결 테스트 실패
**확인 순서:**
1. exec URL이 맞는지 확인 (Dev URL 아닌지)
2. 배포 상태 확인: Apps Script → 배포 → 활성 배포 있는지
3. "실행 대상"이 나(lucky4694@gmail.com)인지 확인
4. "액세스 권한"이 모든 사용자인지 확인

### GAS 수정 후 반영이 안 된다
1. 재배포 했는지 확인: 배포 관리 → 기존 배포 편집 → 새 버전 → 배포
2. 브라우저 강력 새로고침: Ctrl+Shift+R
3. ⚠️ "새 배포"(완전 새로 만들기)하면 URL이 바뀜

### Unknown type 에러
- doPost에서 type 필드를 못 찾는 것
- 프론트엔드에서 `action`으로 보내고 있을 수 있음 → `type`으로 수정
- GAS 재배포 안 됐을 수 있음

### MailApp 권한 오류
- appsscript.json에 gmail.send 범위 추가
- GmailApp.sendEmail() 사용 (MailApp 대신)

## UI 표시 문제

### 화면이 깨져 보인다
1. Ctrl+Shift+R (강력 새로고침)
2. 그래도 안 되면 F12 → Application → Clear site data

### 언어가 이상하게 섞인다
- 왼쪽 하단 언어 전환 버튼 클릭 (한국어↔日本語)
- localStorage.getItem('kyuyo_lang')으로 현재 언어 확인 가능

### 모바일에서 PC 화면이 나온다
- URL에 /mobile.html 직접 접속
- 또는 URL에 ?force_mobile=1 추가

### 글자가 너무 작다/크다
- 왼쪽 하단 A- / A+ 버튼으로 조절
- 설정은 자동 저장됨

## 행정 관련

### 주민세 납부서가 안 왔다
**원인:** 給与支払報告書 제출 시 「納入書不要」를 선택한 경우  
**해결:** 해당 시/구청 특별징수 담당 부서에 재발행 요청  
**필요 정보:** 사업자명, 특별징수의무자 번호, 해당 연도

### 협회けんぽ 보험료율이 변경됐다
1. WisePay → 보험료율 설정 → 최신 요율 가져오기 (자동 스크래핑)
2. 적용 시작월 확인 후 저장
3. 건강보험: 3월분부터 / 고용보험: 4월분부터

## 개발자 디버그 도구

### 브라우저 콘솔(F12)에서 사용 가능한 명령

```javascript
// 현재 사원 목록
console.log(employees)

// 지급완료 연월 목록
console.log([...paidYMs])

// 특정 월 저장 여부 확인
console.log(_isMonthSaved('2026-05'))

// 미송금 저장월 확인
console.log(_getLatestUnpaidSavedMonth([...paidYMs]))

// JST 현재 시간 확인
console.log(_jstNow())

// 알림 테스트 (day < 10 → 노란 말풍선)
_testAlert(5)

// 알림 테스트 (day >= 10 → 파란 말풍선)
_testAlert(11)

// 알림 1번 이메일 테스트
_testAlert1()

// localStorage 알림 제한 리셋
localStorage.removeItem('lastSendReminderEmail')
localStorage.removeItem('lastPayConfirmReminderEmail')
localStorage.removeItem('lastDataInputReminderEmail')

// 송금완료 테스트 데이터 리셋
localStorage.removeItem('kyuyo_paid_yms')
```
