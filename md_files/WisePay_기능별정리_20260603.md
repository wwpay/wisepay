## 🏗 아키텍처

```

        ↕
```

## 🔐 인증 (auth.js)

| 항목 | 내용 |
|---|---|
| 방식 | SHA-256 해시 비밀번호 |
| 계정 | wiseadmin (관리자), wisejp (열람자) |
| 세션 | 장기(persistent) / 세션 타입 |
| 자동 로그아웃 | 열람자 1시간 idle 후 자동 로그아웃 |
| 아이디 저장 | localStorage (wisepay_saved_id) |
| 비밀번호 변경 | 설정 화면에서 본인 비번 변경 가능 |
| 사용자 관리 | admin만 열람자 비번 재설정 가능 |

## 👤 사원 관리 (employees.js)

- Primary Key: 사원번호(empNo) — index 기반 금지, 재사용 불가
- 소프트 삭제: deleted: true 플래그
- 퇴사자: 퇴/退 배지 표시, 기본 숨김, toggleShowResigned로 표시
- GAS deleted_emp_ids 시트로 관리
- 부양가족: families 배열 → fuyou(부양수) 자동 연동
- 사원 폼: 재직/퇴사/신규 상태별 버튼 분기

- 표준보수월액: 수동입력 (법적 이유)
- 随時改定: 担당자 확인 구조

## 🔒 송금 완료 기능

### 처리 흐름
급여 입력 → 저장 → 실제 은행 송금 → 🔒 송금 완료 클릭 → 잠금

### 완료 시 처리
- 給与スナップショット 시트에 회계 증빙 기록
- 지급완료이력 시트에 확정자/확정일시 기록
- 입력란 잠금
- 브라우저 푸시 알림 발송

- 🔓 수정 버튼 클릭 → 확인 다이얼로그 → 잠금 해제

## 🔔 알림 기능 (notifications.js, service-worker.js)

### 알림 종류
| # | 조건 | 방식 | localStorage 키 |
|---|---|---|---|
| 1 | 익월 1일~ + 전월 저장 없음 | 이메일만 | lastDataInputReminderEmail |
| 2 | 저장됐는데 송금완료 없음 + day < 10 | 말풍선(노란) + 이메일 | lastSendReminderEmail |
| 3 | 저장됐는데 송금완료 없음 + day >= 10 | 말풍선(파란) + 이메일 | lastPayConfirmReminderEmail |
| 푸시 | 송금 완료 클릭 | 브라우저 푸시 | — |

- wiseadmin 전용, 이메일 수신: lucky4694@gmail.com
- 이메일 하루 1회 제한

### 말풍선 스펙
- 위치: 헤더 바 중앙 인라인 (overflow: hidden)
- 애니메이션: riseAndBounce (헤더 아래 → 중앙으로 올라옴)
- 2번 색상: #FFFBEB / #FCD34D / #92400E
- 3번 색상: #EFF6FF / #93C5FD / #1E40AF
- 확인 버튼: 잠깐 닫힘, 조건 충족 시 다음 접속에 재표시

### GAS 이메일 함수
| 함수 | 용도 |
|---|---|
| sendDataInputReminderEmail | 급여 미입력 알림 |
| sendPayrollReminderEmail | 송금 독촉 |
| sendPayConfirmReminderEmail | 송금완료 버튼 독촉 |
| sendConfirmationEmail | 송금완료 확정 통지 |

## ☁️ GAS 연동 (gas.js, WisePay_GAS.gs)

### 통신 방식
- doPost: JSON 바디 `type` 필드로 액션 구분
- doGet: URL 쿼리 파라미터 `?action=` 방식
- gasRequest(): 15초 타임아웃, 에러 핸들링 포함

### 주요 시트
| 시트명 | 내용 |
|---|---|
| 사원정보 | 사원 마스터 |
| 급여데이터 | 월별 급여 입력값 |
| 지급완료이력 | 송금완료 기록 (확정자, 일시) |
| 給与スナップショット | 송금완료 시 회계 증빙 |
| 보험료율데이터 | rateHistory |
| users | 사용자 계정 (ID, 해시, 역할) |
| deleted_emp_ids | 소프트 삭제 사원 ID |
| WisePay로그 | 조작 로그 |
| 백업이력 | 자동 백업 기록 |

### freee CSV 업로드
- freee 人事労務 CSV → 급여 데이터 자동 파싱
- 일본어 항목명 자동 매핑
- 급여 귀속 연월 자동 판정 (익월 지급 기준)
