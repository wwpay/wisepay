# WisePay 월간 업무 매뉴얼

> 앱 정식명: 「給与Pro by Wisewires」/ 약칭: WisePay（와이즈페이）  
> 급여일: 익월 10일 (10일이 토/일/공휴일이면 앞당김)

---

## 한 달 타임라인 한눈에 보기

```
전월 말일
  └─ 잔업비 집계 대기 중...

익월 1일 (새 달 시작)
  └─ [알림 1] 급여 데이터 미입력 이메일 수신 가능
  └─ 잔업비 확정되면 → 급여 입력 시작

1일~9일
  └─ 급여 입력 완료 → 저장 (✅)
  └─ [알림 2] 말풍선 + 이메일: "송금 기한 10일까지"
  └─ 5일~9일: 은행 송금 예약 (9일은 익일 예약 불가 주의)

10일 (급여일)
  └─ 은행 자동 송금 실행
  └─ [알림 3] 말풍선 + 이메일: "송금 완료 버튼 누르세요"

10일 이후 (은행 계좌 확인 후)
  └─ WisePay에서 🔒 송금 완료 버튼 클릭
  └─ → 브라우저 푸시 알림 수신
  └─ → 급여스냅샷 저장, 입력란 잠금
  └─ → 알림 배너 사라짐

말일
  └─ 이번 달 작업 완료 ✅
```

---

## 상세 업무 순서

### STEP 1 — 급여 데이터 입력

**시기:** 잔업비 확정 후 (보통 익월 1일~4일)

1. WisePay 접속 (https://wwpay.netlify.app)
2. 급여 명세 화면에서 해당 월 선택
3. 사원 드롭다운에서 사원 선택
4. 입력 항목:
   - 기본급 (월급제는 고정값)
   - 잔업수당 (残業代) — 매월 변동
   - 근무수당 / 직무수당 / 현장수당
   - 비과세 교통비
   - 표준보수월액(標準報酬月額) — 변경 시만 수정
   - 주민세(住民税) — 6월 갱신 주의
   - 연말정산 정산액 — 해당 월만 입력
5. 자동 계산 확인:
   - 건강보험료, 개호보험료, 자녀육아지원금
   - 후생연금, 고용보험료
   - 소득세 (세액표 자동 적용)
6. 전 사원 입력 완료 후 → STEP 2

> ⚠️ 주민세는 매년 6월에 시청 납세통지서 기준으로 갱신

---

### STEP 2 — 저장

**시기:** 전 사원 급여 입력 완료 후

1. 각 사원별로 **저장** 버튼 클릭
2. 상태 표시가 📋(노란) → ✅(초록)으로 변경 확인
3. Google Sheets에 데이터 저장됨

> 저장하지 않으면 송금 완료 버튼 활성화 안 됨

---

### STEP 3 — 은행 송금 예약

**시기:** 저장 완료 후, 급여일 전날까지  
**권장 시기:** 5일~8일 (9일은 익일 예약 불가인 경우 있음)

1. WisePay 인쇄 또는 PDF 저장으로 급여 명세 확인
2. 은행 인터넷뱅킹에서 각 사원 계좌로 송금 예약
3. 금액: 차인지급액 (총지급 - 총공제) 확인

> ⚠️ 급여일(10일)이 토/일/공휴일이면 앞 영업일로 변경

---

### STEP 4 — 송금 완료 확인

**시기:** 급여일(10일) 이후 은행 계좌 확인 후

1. 은행 계좌에서 송금 완료 확인
2. WisePay 급여 명세 화면에서 🔒 **송금 완료** 버튼 클릭
3. 확인 다이얼로그 → 확인
4. 완료 시:
   - 상태 ✅(초록) → ✓ 송금 완료(파란, 비활성)로 변경
   - 급여스냅샷 시트에 회계 기록 저장
   - 입력란 잠금 (실수 수정 방지)
   - 브라우저 푸시 알림 수신
   - 알림 말풍선 사라짐

> ✅ 이 달 작업 완료!

## 연간 정기 작업

### 매년 3월 — 건강보험료율 갱신
- 협회けんぽ에서 새 요율 발표 (도쿄도 기준)
- WisePay → 보험료율 설정 → 최신 요율 가져오기 (자동 스크래핑)
- 적용 시작월: 3월분 급여부터

### 매년 4월 — 고용보험료율 갱신
- 후생노동성 발표 확인
- 자녀육아지원금(子ども・子育て支援金) 요율 확인
- WisePay → 보험료율 설정 → 수동 입력

### 매년 6월 — 주민세(住民税) 갱신
- 시청 납세통지서(특별징수 税額通知) 수령
  - ⚠️ 납입서불요(納入書不要) 선택 시 통지서 안 옴 → 시청에 재발행 요청 필요
- 전 사원의 주민세 금액을 6월분부터 변경 입력

### 매년 10~11월 — 정기算定 확인
- 4~6월 평균 기준 표준보수월액 갱신 (9월부터 적용)
- 협회けんぽ 통지서 확인 후 WisePay 사원정보에 반영

### 연말 — 年末調整(연말정산)
- 12월분 급여에 연말정산 정산액 입력 (플러스/마이너스)
- 임금대장 출력 → 세무사 제출

## 임시 작업

### 사원 입사 시
1. WisePay → 사원 관리 → 신규 사원 등록
2. 사원번호 지정 (재사용 불가)
3. 입사일, 생년월일, 부양가족 입력
4. 표준보수월액 초기값 입력
5. 다음 급여 처리부터 자동 포함

### 사원 퇴사 시
1. WisePay → 사원 관리 → 해당 사원 → 퇴사일 입력
2. 저장하면 퇴/退 배지 표시, 목록에서 기본 숨김
3. 마지막 급여 처리 후 송금 완료까지 완료

### 표준보수월액 변경 시 (随時改定)
1. 변경 요건 확인: 고정급 변경 + 3개월 연속 + 2등급 이상 차이
2. 협회けんぽ 届出 수리 확인
3. WisePay 사원정보 → 표준보수월액 수정
4. 적용 시작월부터 보험료 자동 반영

## 화면별 용도 빠른 참조

| 화면 | 주요 용도 |
|---|---|
| 급여 명세 | 월별 급여 입력, 저장, 송금 완료 처리 |
| 지급 이력 | 사원별 과거 지급 내역 조회 |
| 임금대장 | 연간 임금대장 인쇄/PDF (세무사 제출용) |
| 사원 관리 | 사원 등록/수정/퇴사 처리 |
| 보험료율 설정 | 요율 조회, 최신 요율 자동 취득 |
| 설정 | GAS URL 설정, 백업/복원, 사용자 관리 |
