# WisePay 웹앱 개발 종합 — 개발 히스토리 (시간순)

> 앱 정식명: 「給与Pro by Wisewires」/ 약칭: WisePay（와이즈페이）  
> 개발자: Wisewires 주식회사 일본지점 지점장  
> 목적: 일본 노동법 기반 급여 계산 웹앱 (소규모 사업장용)  
> 배포 URL: https://wwpay.netlify.app  
> GitHub: lucky4694-github/WisePay

---

## 1단계 — 기획 및 설계

- Gemini 초안 파일 존재 → 검토 후 자체 설계로 전환
- 구글 드라이브(Google Sheets) DB 연동 방식으로 결정
  - localStorage는 브라우저 캐시 삭제 시 데이터 소실 → 부적합
  - Sheets = 무료, 엑셀 열람 가능, 자동 백업
- 기술 스택: 웹앱(HTML/JS) + Google Apps Script(GAS) + Google Sheets
- 아키텍처: `웹앱 (브라우저) ↕ GAS ↕ Google Sheets`
- UI 언어: 한국어 기본 + 일본어 전환 (toggleLang)

---

## 2단계 — GAS 배포 및 연동

- GAS(WisePay_GAS.gs) → Apps Script 배포
- Dev URL vs exec URL 차이 확립
  - Dev: 본인만 접근, 코드 즉시 반영
  - exec: 모든 접속자, 재배포 필요
- GAS_URL 하드코딩 방식 채택 (환경변수 불가한 브라우저 환경)
- doPost: JSON 바디의 `type` 필드로 액션 구분
- doGet: URL 쿼리 파라미터 `?action=` 방식

## 3단계 — 보험료 요율 시스템

- 협회けんぽ 요율을 rateHistory 배열로 관리 (from:'YYYY-MM' 형식)
- 현재 적용 요율 (2026년 4월~):
  - 건강보험(도쿄): 9.85%, 개호보험: 1.62%, 자녀육아지원금: 0.23%
  - 후생연금: 18.30%, 고용보험(근로자): 0.50%
- 보험료율 자동 스크래핑: GAS가 협회けんぽ 공식 사이트에서 취득
- 표준보수월액(標準報酬月額): 수동입력 유지
  - 법적 이유: 協会けんぽ届出 수리 후 효력 발생
  - 随時改定 자동화 시 법적 위험 → 담당자 확인 구조 유지
- 자녀・육아지원금(子ども・子育て支援金): 2026년 4월부터 0.23% 적용

## 4단계 — Netlify 배포 및 인증

## 5단계 — 사원 관리 기능

- 사원번호(empNo)를 Primary Key로 사용 (index 기반 금지)
- 소프트 삭제: deleted: true 플래그 방식
- 퇴사자 처리:
  - 퇴/退 배지 표시
  - 기본적으로 목록에서 숨김 (toggleShowResigned로 표시)
  - deleted_emp_ids 시트로 GAS 관리
- 사원 폼: 재직/퇴사/신규 상태별 버튼 분기
- 부양가족(fuyou): 자녀 수 기반 자동 연동

## 7단계 — 지급 확정(送金完了) 기능

### 급여 처리 흐름
1. 급여 입력 (기본급, 잔업비, 주민세 등)
2. 저장 (💾) — Google Sheets에 기록
3. 실제 은행 송금
4. 🔒 송금 완료 버튼 클릭
5. 송금 완료 상태 — 스냅샷 저장, 입력란 잠금

### 상태 3단계
| 상태 | 아이콘 | 색상 | 의미 |
|---|---|---|---|
| 임시 저장 | 📋 | 노란색 | 미저장 |
| 저장 완료 | ✅ | 초록색 | Sheets에 저장됨 |
| 송금 완료 | 🔒 | 파란색 | 실제 송금 확정 |

### 처리 내용
- 給与スナップショット 시트에 회계 증빙 기록
- 지급완료이력 시트에 확정자/확정일시 기록
- 입력란 잠금 (수정 방지)
- 🔓 수정 버튼으로 잠금 해제 (확인 다이얼로그 필수)
- 버튼: 🔒 송금 완료(활성) / ✓ 송금 완료(비활성, 완료 후)

## 8단계 — 백업 기능

### 백업 종류
| 파일 | 내용 | 용도 |
|---|---|---|
| 사원_backup_YYYYMMDD.json | employees | WisePay 사원 복원 전용 |
| 급여_backup_YYYYMMDD.json | payrolls + rateHistory | WisePay 급여 복원 전용 |
| Excel 백업 (전체) | 사원+급여 표 형태 | 열람·세무사 공유용 |
| 구글 시트 복사본 | 전체 시트 | 자동 주간 백업 (매주 월요일 오전 9시) |

### 복원 기능
- 사원/급여 각각 독립 복원 (상대방 데이터 불변)
- 부분 복원: 사원 선택 × 월 선택 조합
- 확인 다이얼로그 필수
- 백업 저장 폴더 지정 가능 (File System Access API)

### Undo 기능 (제거됨)
- Command 패턴 기반 설계 → CC 구현 → 재검토 → 전체 제거
- 이유: 유지보수 복잡성
- 대안: 분리 백업 + 부분 복원으로 대체
